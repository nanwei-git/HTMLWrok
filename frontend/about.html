PROJECT OVERVIEW

关于云栖校园

云栖校园服务平台是一个自选的全栈 Web 项目。它以内敛清晰的界面承载校园服务入口， 以标准化的 RESTful 接口连接数据与页面，并以可维护的目录结构为后续功能扩展留出空间。

项目类别 · 自选 全栈实践 持续迭代
01

项目定位

面向校园场景的数字服务入口，强调信息清晰、访问轻量与体验一致。

02

前端原则

仅使用原生 HTML、CSS 与 JavaScript，不引入第三方库、框架或 CDN 资源。

03

后端架构

基于 Node.js 与 Express，采用 RESTful + MVC 分层，所有接口统一使用 /api/ 前缀。

04

数据策略

使用 MySQL 持久化业务数据，数据库凭据隔离在本地环境变量中，不进入代码仓库。

TECH FOUNDATION

技术底座

从浏览器到数据库，保持结构简单且职责明确。

01

HTML · CSS · JavaScript

语义化页面、响应式布局与 Canvas 背景动画，全部由原生能力实现。

02

Node.js · Express

固定 8509 端口，托管前端静态资源，统一处理跨域与 JSON 响应。

03

MySQL · RESTful API

以 yan_ 前缀组织数据对象，通过分层接口提供稳定的数据能力。

PROJECT LAYOUT

目录结构

前后端职责分离，资源与业务代码各归其位。

web_work/
├─ frontend/          # 原生前端
│  ├─ css/            # 样式文件
│  ├─ js/             # 交互与动画
│  ├─ fonts/          # iconfont 资源
│  ├─ images/         # 图片资源
│  └─ index.html      # 项目首页
└─ backend/           # Express 服务
   ├─ config/         # 数据库配置
   ├─ controllers/    # 控制器
   ├─ middleware/     # 中间件
   ├─ models/         # 数据模型
   ├─ routes/         # 接口路由
   └─ server.js       # 服务入口
